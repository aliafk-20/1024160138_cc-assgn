2. Run it from the top with **Runtime → Run all**, or cell by cell.
3. Each notebook prints `Name: Ali Ekram | Roll No: 1024160138 | Group: 3P14` in its first output cell.

Requirements are all standard in Colab: Python 3, `numpy`, `pandas`, `matplotlib`, `nltk` and `scikit-learn`.
Locally: `pip install numpy pandas matplotlib nltk scikit-learn notebook`.

### Assignment 4 — FAQ system (Pandas)
- The last two digits of the roll number (3 and 8) give the categories of the two personalised entries: `billing` and `general`.
- Scoring: a query term earns 2 points if it is one of an entry's keywords, 1 point if it only appears in the question, and the total is divided by 2 × the number of query terms (filler words are ignored).
- Q4 asks for a new keyword by typing. If you don't type one, the demo keyword `annual` is used. **Type your own keyword when you run it in Colab**, then download the CSV from the Files panel (folder icon) on the left.

### Assignment 6 — NumPy-II
- Q4 follows the given OLS formula `w = (XᵀX)⁻¹Xᵀy` with no intercept column; the result is cross-checked against `np.linalg.lstsq`.

### Assignment 7 — NLP-I
- **Run the starter notebook (`UCS420_LA9_Starter.ipynb`) first**, in the same Colab session, so your own `tickets`, `TEST_LINES` and `process_ticket()` are used.
- If the starter is not loaded, the notebook falls back to a stand-in dataset (not your own tickets).
- The `analyze()` function in the "Dataset hooks" cell maps the output of `process_ticket()` to the six counts needed. If your starter uses different key names, edit only that function.
- The first cells download the NLTK data (`punkt`, `stopwords`, `wordnet`, tagger), so an internet connection is needed.
- The Q6 interpretation text is generated from your data when you run the notebook.
- Do not edit `generate_dataset()` or `process_ticket()` in the starter.
